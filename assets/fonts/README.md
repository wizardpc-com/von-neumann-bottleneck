# Interface font

Noto Sans SC is bundled unchanged for consistent Chinese and Latin interface text.

- Source: [Google Fonts, Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc)
- Upstream file: `NotoSansSC[wght].ttf`, downloaded 2026-09-07.
- License: [SIL Open Font License 1.1](OFL-NotoSansSC.txt), included with the font and distribution.
- `interface_regular.tres` selects weight 450 from the original variable font; `interface_heading.tres` selects 600. Numeric OpenType tags are used because this Godot build ignores the string key during resource loading.
- Font SHA-256: `a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da`.

Circuit symbols, chapter emblems, panel decoration and Handbook diagrams are original code-drawn artwork. No Turing Complete assets are included.
