开始 / Getting started
实验室点击终端或按 Enter，选择开始／继续；旅程板与终端的旅程入口可选任务。
Click the laboratory terminal or press Enter, then Start/Continue. The journey board and terminal Journey action open task selection.
按任务要求搭建、接线、编辑，显式运行后查看真实结果，修改再试。创造作品需要明确命名并保留。
Build, wire and edit for the task, explicitly Run, inspect the actual result, then revise. Name and Keep creative works explicitly.
Esc 返回／取消；F10 设置；F8 现场反馈；F11 全屏。Mac 撤销 ⌘Z，Windows 撤销 Ctrl+Z。
Esc returns/cancels; F10 opens settings; F8 opens feedback; F11 toggles fullscreen. Undo: ⌘Z on Mac, Ctrl+Z on Windows.
语言可在终端或设置选择中文／English。
