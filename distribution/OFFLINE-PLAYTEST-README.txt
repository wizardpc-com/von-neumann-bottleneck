《冯·诺依曼瓶颈》队友试玩说明

一、打开与选关

1. 完整解压 ZIP，再双击 Windows/Von-Neumann-Bottleneck.exe。
   不要在压缩包预览里运行。无需安装 Godot/Python，无需账号或网络。
2. 首页是实验室。点击桌上屏幕或按 Enter 唤醒终端，点主按钮开始/继续。
3. 想自由选关，点终端「旅程」或右墙旅程板，在地图里选章节和任务。
   本包全部 60 个任务入口开放。入口开放不算通关，实际任务、测试与
   完成条件仍然有效；不会附送别人的通关档、作品或训练好的模型。
   这是正常 Game 规则的全入口试玩包，不是开发用 Test 模式。
4. F10 打开设置，F11 切换全屏；终端右上角可切换中文/English。

第一次建议先做 NOT 教程：跟着步骤卡放元件、接线、改变输入和运行。
输入 1 时 NOT 输出 0，灯灭也正确。完成后回实验室看看地球仪与档案架。
不必一次玩完全部任务；觉得难找、看不懂、操作不顺都可以直接反馈。

二、常用操作

- 放元件：从元件台拖入画布，或点击后放置；右键/Esc 取消放置。
- 接线：输出接兼容输入。交叉线不会自动相连；圆端口是一位信号，
  方端口是多位总线。先照任务台的具体目标操作。
- 测试：调试看一个输入，完整测试检查正式用例；一个例子正确不等于通关。
- 回放：用播放/暂停/单步观察运行；播放速度不影响模拟结果。
- 改错：Ctrl+Z 撤销，Ctrl+Y 重做；文本框里优先撤销文字编辑。
- 求助：打开任务台/手册，或逐层看 Hint；后两层提示会先确认。
- 离开：按界面保存草稿/方案并处理保存提示，再返回地图或实验室。
  从设置正常退出，下次点继续。不要通过删存档换关。

硬件测试入口可能提供标明「测试参考」的临时前置组件，方便直接试验。
使用参考组件不能记录真实通关或封装成果；你的自制组件不会被覆盖。

三、想快速体验“压缩 → 预测 → 创造”

在旅程地图找压缩 C1–C3、内容预测 P1–P3、创造 G1–G3。
推荐先走 C1 → P1 → G1，再去 G3 留下作品：

1. C1：选样例 → 从当前样例学习 → 发送预测包并复原。
2. P1：练习 → 先提交预测 → 再揭晓真值，完成整轮；可用执行余段。
3. G1：断开真值、接上回灌 → 按我的配方生成。
4. G3：填写作品名并保存当前作品。

只打开页面不会完成上述步骤。改样例或记忆长度后要重新学习，复原与
整轮预测条件也要重新满足。最短路线不等于完成全部九项。
实验室作品墙与档案显示真实保存内容；查看旧作品不会自动生成新作品。

四、遇到问题：按 F8，结束时发一个 ZIP

1. 按 F8 或点「现场反馈」。未通关也能写，游戏会暂停。
2. 选类型，写清“在哪一关、做了什么、以为会怎样、实际怎样”。
   游戏自动保留打开反馈前的游戏截图、当前方案、参数与运行现场，
   文字自动保存在本机。点「记下这条反馈」整理，未整理的草稿也会导出。
3. Esc/F8/返回游戏可继续。多次玩、多次重启都可以继续积累反馈。
4. 试玩结束时点「导出全部反馈」，把最新导出的一个 ZIP 发给维护者。
   最后再导出一次即可包含之前的反馈；无需逐张找截图或日志。

导出不会删除原件，也不会自动上传。失败时先保留面板文字，用「另存到…」
选可写位置；完成导出后再退出。反馈包含游戏截图、自由文字、作品、
日志与存档副本，请不要写密码或私人信息，确认后再分享。
截图只取游戏窗口，不采集桌面、麦克风或摄像头。

六、存档与更新

本包采用独立测试存档，不读取或迁移普通版的进度。
新的命名 profile 与旧测试 profile 分开；同名 profile 按下述规则继续。
构建时会把下面两个目录替换为本包实际 profile：
%APPDATA%/VonNeumannBottleneckCandidates/representation/OfflineTeammate/
%APPDATA%/VonNeumannBottleneckCandidates/service/OfflineTeammate/

反馈在 representation 目录的 offline_playtest/；创作、实验室记录也在
这份 profile 内。更新或回退前正常退出，再备份上述两个完整目录。
不要只备份主进度文件，不要导入维护者的 QA 通关档，不要删除旧档。
同名 profile 的新版会继续已有存档；换解压目录并不会换存档空间。
不要同时启动多个实例操作同一份存档。遇到较新格式拒绝保存时，
保留原文件并反馈，不要删档强行继续。

feedback-tools/ 是维护者的 Python 导入与分析工具，同学不必执行。

Run the extracted Windows EXE. Click the terminal or press Enter to begin.
All sixty task entrances are available; entry grants no completion or saved work.
Press F8 to capture a scene and write a local autosaved note. At the end, export
all feedback once and deliberately share the latest ZIP. No account, server or
network is used. Back up both complete profile directories before updating.
