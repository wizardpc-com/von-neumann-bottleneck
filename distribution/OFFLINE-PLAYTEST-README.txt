《冯·诺依曼瓶颈》离线队友试玩版 / Offline teammate pre-version

解压整个文件夹，运行 Von-Neumann-Bottleneck.exe。无需账号、网络或 Python。
这是测试者版本：任务树的全部 60 项可直接进入；进入不等于通关，运行与模型
规则仍然有效。推荐从序章开始，也可以直接选择你要检查的章节。
硬件关卡提供标注“测试参考”的临时前置组件，方便直接试验；使用它们不能
记录真实通关或封装成果。你已有的自制组件优先使用，不被参考组件覆盖。

随时反馈
1. 按 F8，或点右下角“现场反馈”。已有工作台反馈按钮也通向同一个入口。
2. 游戏暂停，自动记录打开面板前的游戏截图、当前方案、编辑文字、参数、
   运行结果/轨迹和游戏现场。选择类型并写下问题，文字会自动保存。
3. “记下这条反馈”标记为已整理；未标记的草稿也会保留并导出。
   Esc / F8 / “返回游戏”继续试玩。历史下拉框可以补充旧意见；旧现场不变。
4. 结束后点右下角或面板中的“导出全部反馈”，系统生成并核验一个 ZIP，
   打开其所在文件夹。把这个 ZIP 发给维护者即可；无需寻找多个截图或日志。

导出不会删除本机原件。遇到保存或导出失败，会显示原因；请使用“另存到…”
选择可写位置。失败时不要直接关程序，先保留文字并完成导出。
电脑断电/硬盘故障仍可能造成损失；重要反馈建议结束时导出并自行另存一份。

文件仅保存在本机；本版本没有反馈服务器，也不会自动上传。截图只取游戏
窗口，不取桌面、麦克风或摄像头。现场包包含游戏作品、草稿、自由文字、
操作记录、游戏日志及存档副本，请勿写入密码或私人信息，并有意识地分享。
快照用于定位与分析，不能保证每一个 UI 状态都可自动重放。缺失、截断或
无截图会明确记录。单文件 64 MiB、单包展开后 1 GiB；超限不清空原件。

独立存档与反馈目录（Windows）
%APPDATA%/VonNeumannBottleneckCandidates/representation/OfflineTeammate/
服务存档在同级 service/OfflineTeammate/。反馈在上述 representation 目录的
offline_playtest/；记录跨重启保留。更新前备份两个完整目录，勿删除旧存档。
不要同时启动多个本版本实例操作同一份存档。

维护者：feedback-tools/ 下附 Python 离线导入与分析工具及说明。
