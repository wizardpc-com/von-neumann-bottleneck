Von Neumann Bottleneck — Eight-task Demo
=======================================

Extract the ZIP and double-click Von-Neumann-Bottleneck.exe. Godot and an account are not required.
Choose Start game for the mainline, Continue game to resume, or Hardware workshop for optional gate construction.
Run checks the current design. Completion is recorded immediately; you can keep optimizing before Continue.
P-1/P-2: drag ports to connect; change input values to preview; Step commits storage. F5 runs full validation.
Program tasks: edit the draft, then Run. Undo/Redo and Handbook are available. F11 switches fullscreen.
Play/Pause, the event slider and 1x/2x/4x inspect completed results. The Handbook includes your verified experiences.
From the task menu, Export playtest records writes a local JSON file. Share it with the developer if you choose.

Mainline saves use demo_progress_v1.json, independently of older workshop files. Start does not reset old work.
The game stores anonymous local events. It does not upload data. Human pacing, clarity and mouse-comfort acceptance remains open.

冯·诺依曼瓶颈 — 八关 Demo
======================

解压后双击 Von-Neumann-Bottleneck.exe，无需安装 Godot 或登录账号。
选择“开始游戏”进入主线，“继续游戏”恢复当前阶段与草稿；“硬件工坊”为可选深入内容。
运行当前方案后立即记录达标，可以继续优化，也可以点击“继续”。
P-1/P-2：拖动端口接线；改变输入预览；“单步”提交一次保存状态。F5 验证全部用例。
程序关：编辑后直接运行；上方提供撤销、重做与手册。F11 切换全屏。
播放/暂停、事件滑条与 1×/2×/4× 用于查看已完成的结果；手册附有已验证经历。
任务菜单中的“导出试玩记录”生成本地 JSON；你可以自行决定是否发给开发者。

主线使用独立的 demo_progress_v1.json；开始游戏不会清除旧工坊方案。
游戏只在本地记录匿名事件，不会上传数据。新人可解性、节奏和鼠标手感仍待真人试玩。
