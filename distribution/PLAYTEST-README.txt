Von Neumann Bottleneck — Friend Playtest
=========================================

1. Extract the ZIP to a normal writable folder.
2. Double-click Von-Neumann-Bottleneck.exe.
3. Play normally. No Godot installation or account is required.
4. After the final Demo feedback, choose Export Playtest Data and send the resulting JSON file to the developer.

The game stores only anonymous local playtest events and optional feedback. It does not upload data.

冯诺依曼瓶颈 — 朋友试玩
=======================

1. 将 ZIP 解压到普通可写文件夹。
2. 双击 Von-Neumann-Bottleneck.exe。
3. 按正常流程试玩；无需安装 Godot，也无需账号。
4. 完成 Demo 最终反馈后，点击“导出 Playtest 数据”，并把生成的 JSON 发给开发者。

游戏只在本地保存匿名试玩事件与可选反馈，不会上传数据。
