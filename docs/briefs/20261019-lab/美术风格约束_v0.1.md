# 《冯·诺依曼瓶颈》美术风格约束 v0.1

> 用途：供美术同学、Claude、Codex 与图像生成使用。本文档用于约束整体视觉方向与资产制作边界，避免风格发散与返工。

---

## 1. 总体目标

本游戏的视觉不以“炫技”或“强冲击”为目标，而以 **清晰、统一、可信、安静** 为优先。

核心目标：

1. 让玩家觉得这是一个 **温润、简洁、未来主义** 的计算机解谜游戏。
2. 让游戏世界观中的“新文明”显得 **稳定、成熟、秩序良好**。
3. 让玩家实际操作的“终端 / 实验台”显得 **理性、克制、可读性强**。
4. 美术必须服务于玩法理解，**不能遮挡计算过程、信号状态、元件关系与任务目标**。

## 2. 风格关键词

### 正向关键词

- 极简未来主义
- 温润
- 安静
- 克制
- 清晰
- 精密
- 宽广
- 可信赖
- 低饱和
- 有秩序

### 避免的关键词

- “到处都很炫但看不清信息”

## 3. 空间层次设定

整个游戏的主要视觉分为两层：

## A. 外部空间 / 实验室 / 新文明环境

### 气质
- 明亮
- 温和
- 宽广
- 圣洁但不过于宗教化
- 稳定、成熟、有人维护的未来空间

### 视觉特征
- 大面积留白
- 柔和光照
- 结构简洁
- 少量蓝白灰层次
- 可带轻微纪念性、档案感、研究设施感

### 主色方向
- 白色
- 浅灰
- 灰白
- 柔和蓝
- 少量青蓝点缀

### 用途
- 首页
- 开场实验室
- 文明空间
- 叙事场景
- 档案空间 / 外部空间

---

## B. 内部空间 / 操作终端 / 计算工作台

### 气质
- 深色
- 安静
- 理性
- 稳定
- 简洁
- 专注

### 视觉特征
- 深灰 / 蓝灰底色
- 低饱和青色或柔和蓝色点缀
- 控件边界清晰
- 元件、线路、信号、按钮、提示信息层级明确
- 整体像“未来研究终端”，而不是传统炫酷黑客界面

### 主色方向
- 深灰
- 石墨灰
- 蓝灰
- 深青灰
- 少量柔和青色 / 浅蓝强调色

### 用途
- 关卡核心工作台
- 终端界面
- 元件交互区域
- 工作面板与提示面板

---

## 4. 视觉关系约束

1. **外部实验室可偏亮，终端必须偏深。**
2. **两者必须属于同一个世界。** 不可做成两种完全无关的风格。
3. 实验室与终端应共享：
   - 字体气质
   - 图形语言
   - 边角/面板风格
   - 点缀色逻辑
4. 终端中的信息优先级高于装饰效果。
5. 任何背景、装饰、纹理、发光效果都不能影响：
   - 线路可读性
   - 元件输入输出辨识
   - 任务目标理解
   - 文本清晰度

---

## 5. UI / 控件风格约束

### 控件整体要求
- 扁平化或轻拟物，但偏简洁
- 轮廓清楚
- 层级明确
- 状态明显（正常 / 悬停 / 按下 / 禁用 / 焦点）
- 不依赖复杂纹理堆砌质感

### 推荐特征
- 统一圆角或统一小圆角
- 面板边界适度可见
- 重点按钮有明确强调色
- 列表和选中项有稳定识别方式
- 文本留白足够
- 信息密度适中，不显拥挤

### 不推荐特征
- 过多发光外描边
- 彩色渐变乱用
- 巨大阴影和复杂玻璃拟态
- 过多虚拟扫描线、噪点、网格装饰

---

## 6. 元件 / 图标 / 小资产风格约束

### 元件与图标要求
- 几何清楚
- 能快速辨认含义
- 可统一成一套语言
- SVG 优先
- 不追求复杂细节
- 可适当加入轻微未来仪器感

### 适合的资产类型
- SVG 小图标
- 简洁元件示意图
- 统一风格的按钮图标
- 规则说明小图
- 章节入口图标
- 成长档案 / 手册等功能入口图标

### 不适合
- 每个图标都画成复杂插画
- 过度写实
- 风格不一致
- 颜色使用无统一逻辑

---

## 7. 叙事插图 / 场景图约束

叙事图用于补充世界观与情绪，不替代核心玩法信息。

### 允许的方向
- 温和的未来设施
- 档案感 / 纪念感图像
- 实验室空间
- 未来城市 / 文明场景
- 具有“历史回响”感的简洁视觉

### 约束
- 不要把完整大段正文直接烘焙进图片
- 不要用图片取代系统按钮、任务文字或核心交互信息
- 插图应当可替换，可单独移除，不影响流程

---

## 8. 叙事气质约束（供美术配合）

世界观核心气质：

- 新文明已经建立稳定秩序
- “壹”仍然存在，但在尝试逐步退出神明式角色
- 玩家通过学习程序理解计算，也逐步接触过去的历史
- 游戏整体基调不是黑暗绝望，而是 **理性反思 + 温和重建 + 重新获得判断能力**

因此美术必须避免：

- 纯末日恐怖感
- 过度宗教神权压迫感
- 夸张热血救世主感
- 廉价神秘主义

更适合：

- 温和的纪念性
- 克制的庄重
- 人与技术重新建立关系
- 文明与实验并存的空间感

---

## 9. 资产制作优先级

### 第一优先级（先做）
1. 实验台 / 终端主界面视觉
2. 基础按钮、面板、弹窗、列表风格
3. 基础色板与字体风格
4. 一套核心 SVG 图标 / 元件示意
5. 首页 / 实验室的视觉方向图

### 第二优先级
6. 开场导入插图
7. 通关反馈相关插图
8. 成长档案 / 手册等功能区配图
9. 少量叙事档案图

### 第三优先级
10. 更完整的实验室场景扩展
11. 更细的装饰元素
12. 更丰富的章节性视觉差异

---

## 10. 工作流约束

1. **先做关键界面，再做全套资产。**
2. 先在真实工作台上验证风格，不先追求首页包装。
3. 程序绘制与图片资产并存：
   - 控件与布局优先程序实现
   - SVG / PNG 负责关键视觉与小资产
4. 每一类资产需注明：
   - 用途
   - 尺寸 / 比例
   - 格式（SVG / PNG / 可编辑源文件）
   - 作者
   - 来源 / AI辅助说明
5. 任何新资产接入前，都要检查：
   - 是否影响可读性
   - 是否与整体风格一致
   - 是否值得投入当前时间成本

---

## 11. 一句话总括

**这是一个“温润、安静、克制的未来实验空间”中的计算机解谜游戏。**

玩家身处一个明亮而成熟的新文明环境，通过一台深色、简洁、可信赖的计算终端进入计算世界。美术的职责不是喧宾夺主，而是让玩家更愿意进入、停留、理解并继续探索。
