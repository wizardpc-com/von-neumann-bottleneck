## 1. 实验室就是最终页面：在终端上确认退出

| 操作 | 结果 |
|---|---|
| 实验室中按 Esc（待机或唤醒都可以） | 终端屏幕换成「要退出游戏吗？」，焦点在「是，退出」 |
| 终端菜单「退出游戏」 | 同上 |
| 设置里的「退出游戏」（在实验室打开时） | 关闭设置，同样在终端上询问 |
| 选「是，退出」 | 走原有 `GlobalSave.request_quit()`：先保存，成功后退出；保存失败仍显示原有的失败对话框 |
| 选「否，留下」或再按 Esc | 回到终端菜单 |

档案阅读器、设置、手册等打开时，Esc 仍先关闭它们。工作台内（屏幕上没有终端）的设置退出按钮仍直接退出。
原来在实验室按 Esc 打开设置；现在设置通过终端「设置」或 F10 打开。

## 2. 两个世界

| 层 | 实验室（外） | 终端（内） |
|---|---|---|
| 光 | 自然日光、物体有接触阴影与顶部高光 | 自发光：屏幕顶部的一道冷光，边缘渐暗 |
| 色 | 暖白、石灰、浅木色桌面（`lab_palette.gd` 的 LAB_*，整体偏暖） | 深蓝黑、青色信号光（TERM_*，未改） |
| 空间 | 透视房间、窗、墙、陈设 | 平面信号场：淡青网格（每 4 格一条主线）、屏幕内框与四角定位角标 |
| 电路画布 | — | 统一为深蓝黑底与淡青网格（之前是中性灰黑），与周围终端场一致 |

**进出过渡（`src/ui/terminal_passage.gd`）：** 离开实验室时终端菜单先淡出，镜头推入屏幕，屏幕收成一条横向光线；
下一个终端内场景从这条光线向上下展开。只在从实验室进入时播放一次（4 秒内），减少动效与 headless 下不播放；
动画不改变任何结果，也不长时间拦截输入。返回实验室时仍是原有的从屏幕里拉出。

## 4. 设置面板重构

标题改为「设置」，下附一行说明（F10 打开、Esc 关闭、修改立即生效且不影响进度与存档）。内容分成五张卡片：

- 语言与文字：界面语言、壹的文字速度
- 显示：全屏 · F11、减少动效、画面帧率
- 声音：音效开关与音量、运行氛围及其音量
- 反馈与隐私
- 支持与诊断

选项改为左侧标签、右侧控件；音量滑块与百分比同一行；说明文字缩小变灰。
所有原有节点名（`LanguageChoice`、`ResetPresentation`、`SettingsScroll` 等）与焦点顺序保留。
