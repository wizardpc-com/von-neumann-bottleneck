## 已知限制与不扩大范围的理由

- **同配方重复 Fork 的重开歧义：** 既有格式无法区分“再次从B分叉同一配方”与“已保存同父同配方子作品C”。重开该不可辨状态可能显示已存作品引导；显式Fork仍可用、原作品受保护、当前会话编辑意图有效。精确持久意图需要另定格式；本轮不暗改 schema。
- **界面空间余量：** 英文 Creation 第三标签需横移、Keep有多个现有入口，极端遮挡仍有取舍；旧960逻辑像素fixture的外围裁切不代表正常设计缩放，最终默认缩放探针已核对可见控件边界。已验证主动作可达的路径不因此失效；若最终像素复审确认具体操作被挡，仍应处理该真实障碍，而非将所有布局理想化作为新硬门槛。
- **测试访问与 fixture：** 隔离 Test 档、参考接线或指定任务入口均要明示。实际模型运行与 viewport 输入可以验证相应链，不能证明普通 Game 全解锁、所有60项从头通关或陌生玩家无需帮助。
- **平台与体验：** Windows、导出包、全新人研究、音频／声音身份、长时使用未全面验收。它们单独报告，不自动阻塞本次修订后的基本操作目标。
- **视觉决策：** 清单已交付不等于团队批准某套美术；旧截图不是本次游戏画面。Logo占位及默认实验室尚无标题Logo槽等事实继续保留，暂不擅改。
