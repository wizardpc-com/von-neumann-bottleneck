# 品牌定稿与替换接口 · 2026-11-16

本轮收敛为一套原创几何 VNB 连笔标识。V 的开口、N 的中段收窄与 B 的两个
负形孔构成一个紧凑整体；深石墨、温白与少量低饱和青色沿用实验室／终端的
同一色彩语言。不再沿用芯片箭头占位图，也不加入二进制字符、霓虹或额外装饰。
这是一份可替换的本阶段正式默认稿，不声称已经过外部商标查重或真人偏好研究。

## 接入与替换

唯一配置入口为 [brand.cfg](../../assets/branding/brand.cfg)。默认 `symbol`、
`logo_zh`、`logo_en` 指向温白透明版本，供深色终端与真实玻璃待机面使用；浅底
宣传图使用不带 `-light` 的文件。`BrandIdentity.symbol_texture()` 与
`wordmark_texture(locale)` 只读取配置，不将文件名固化到实验室代码。
原 `title_slot()` 及缺少对应语言素材时的原生文字回退保留。

替换时直接增加新资产、修改配置和 revision，再运行品牌检查与实际 UI 导出
验收。不要因为更换图标而改应用标识或存档目录。构建器从同一配置读取 Windows
和 macOS 原生图标；本页的容器检查不能替代最终 EXE 图标、app/Dock、系统图标
缓存与实际分发包检查。默认实验室／终端接入及包验收由本轮整合证据记录。

## 可复现与验证范围

在带 Command Line Tools 的 Mac 上执行：

```sh
python3 scripts/generate-brand-assets.py
python3 scripts/check-branding.py
```

生成步骤不需要联网或安装 Python 包。它从随仓字体和原创路径重新生成 SVG、
原生图标及审阅图；不同 macOS 栅格器版本可能产生不同 PNG 字节，源码路径
保持相同。最终冻结包以实际 SHA-256 为准，不承诺跨 OS 字节完全一致。

品牌检查验证配置路径、SVG 轮廓与边界、ICO／ICNS 目录和实际 PNG 尺寸。
已实际查看深浅底、黑白及 16–128 像素审阅图；小尺寸保留整体图形与双孔轮廓，
不要求在 16 像素把每个字母独立读作正文。中文与英文完整标题应在适合其比例的
空间显示，不能为了统一宽度将英文长字标挤成不可读的小字。

初次字形轮廓导出存在坐标索引错误，像素审查发现后修正；最终以修正后的可读
中英文审阅图为准。单独配置与静图检查不代表 Godot 最终布局或两平台原生验收。
