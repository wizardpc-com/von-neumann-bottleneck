## 1. 一套引导，同一时间只有一个声音

| 玩家状态 | 现在的表现 | 收起／停止 |
|---|---|---|
| 进入硬件关卡 | 画布上方停靠的引导条：目标一行 + 当前一步；半加器另有四组规格表 | 不自动打开任务大窗；开场气泡在序章本来就不出现 |
| 进入其他关卡且任务卡已展开 | 任务卡里的「现在：」一行短暂提亮 | 不再另外弹出内容相同的开场气泡 |
| 进入其他关卡且任务卡未展开 | 开场气泡出现在导航栏下方 | 不再盖住底部的运行、回放按钮 |
| 主动求助（F1／提示） | 求助文字替换引导条里的当前一步，同一位置给出「再具体一些／我自己试试」 | 步骤正文、高亮圈；若完整说明正打开，先收起说明 |
| 打开完整说明 | 任务窗作为阅读层 | 引导条折叠为一行目标，求助关闭，高亮圈隐藏；关闭后回到当前状态，不重播 |
| 打开设置、手册、结算、提示确认、命名框 | 最上层窗口 | 开场气泡立即离场（不排队补播），高亮圈隐藏 |
| 运行失败 | 引导条写出首个不符项（第几组、哪个输出、期望与实际），高亮圈指向测试台对应行 | 与失败无关的旧提示 |
| 正式用例通过 | 「四组输入都通过了。现在可以封装…」，结算卡给出封装入口 | 不提前称已封装 |

实现：`src/ui/guide_stage.gd` 只做一件事——判断是否有阻断层（设置层，或 `guide_blockers` 组中可见的节点）。
结算卡、试玩反馈层、手册阅读层、提示确认框和命名框加入该组。没有建立通用 UI 框架。

## 2. 硬件序章：停靠引导条

`src/hardware_foundations/tutorial_coach.gd` 从浮在画布上的卡片改为布局中的一行（高度固定 72px，可收起为 40px，收起状态本次会话内保留）。
画布获得剩余高度，引导不再遮挡端口、线路或运行按钮；文字变化不改变高度，拖线时画布不会移动。

- 左列：步骤点、第几步、壹的短回应（逐字输出、句末光标）；中列：目标（小字）和当前一步（立即显示）；右侧：半加器规格表、「完整说明」「收起」。
- `src/ui/yi_help_card.gd` 新增嵌入模式：有引导条时求助放进条内；没有引导条时（已完成关卡、CPU 等）仍在画布右上角。
- `src/hardware_foundations/guide_case_table.gd`：A B 四列 × SUM/CARRY 规格。当前测试台所选输入列高亮；在当前电路上实际运行过的列变绿或红，不符的格子加红框（格内仍是规格值）。点一列只把这组输入放到测试台，不运行、不判定。改线后旧证据立即清空。
- `src/ui/guide_highlight.gd`：首次操作的位置提示圈（呼吸两次后淡出；减少动效时为静止圈）。NOT 依次指向输入 A、测试台 A、运行按钮；搭建关卡指向「元件」、调试运行、正式用例或失败行。阅读层、求助或阻断层打开时隐藏。

### 搭建关卡的状态引导（读真实电路与运行结果）

`hardware_foundations.gd` 中 `_build_guidance()`：

1. 未接线：半加器先请玩家看规格表里 A=1、B=1 的两个输出，再接出其中一个；其他关卡列出还缺来源的输出。
2. 接了一部分：「SUM 已经有来源，CARRY 还没有」。
3. 全部接上：指向调试运行，请玩家选一组输入、对照期望与实际。
4. 调试运行不符：「A=1、B=1 时 SUM 应为 0，实际是 1。看看接到 SUM 的是什么。」数值来自这次 `CircuitTrace`。
5. 正式用例不符：「第 4 组（A=1、B=1）：SUM 期望 0，实际 1。」数值来自 `official_report`／`prologue_report`，高亮失败行。
6. 正式通过：可以封装（封装成功前不说已保存）。

引导只说「往哪里看」，不点名门电路，不按参考解接线；新测试断言引导文字不含 AND／NOT／XOR。
正式用例运行本身也算「试过一组」，避免正式失败后仍停在「试一试」。

## 3. 顶栏与操作区

- `src/ui/workbench_chrome.gd`：去掉大边框，改为一条细底线的轻量导航（按钮高 38→34、标题 21→19）；导航栏加入 `workbench_nav` 组，开场气泡以此定位。
- 硬件：工作台状态（视野、测试结果等）移到导航行右侧；编辑工具与回放工具合为一行（中文 1280 宽单行；英文按需换行）。
- 第一、二、四章：章节名与关卡名同一行，状态提示限两行小字；第二章顶栏由固定 70px 双行变为单行（新测试断言不超过 56px）。
- 运行／调试／正式测试／封装仍在测试台与结算卡，没有收进菜单。设置、退出等低频项的菜单归并本轮未做（见 §6）。

## 4. 第二章「先后有序」等

- 进入关卡时任务卡已展开，开场不再重复弹出同一句话；「现在：」一行短暂提亮。
- `journey_context_card.gd` 新增 `set_live_action()`：`main.gd` 根据实际状态替换「现在：」——程序有未应用修改时「先点应用程序再运行」；正式结果错误时「先在测试台找到第一处不符」；结果正确但超过周期目标时写出实测周期与目标，并指向分析器（无分析器的关卡指向运行记录）。恢复到已应用程序后回到任务原句。替换句用暖色区分。
- 机器图在宿主真实尺寸确定后重新取景，节点文字恢复可读（此前停留在首次布局时的小缩放）。
- 进入关卡时回放栏显示中性的「运行一次测试，查看这次执行记录」，不再说「输入已改变」。
