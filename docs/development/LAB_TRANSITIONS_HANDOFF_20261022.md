# 实验室进出过场与元件台一致性（2026-10-22，Claude）

基线：main `9408519`（代码同 `bfb2ce4`）。本轮改动未提交、未推送。截图证据：[`../verification/20261022-lab-transitions/`](../verification/20261022-lab-transitions/README.md)。

## 用户要求

1. 点击实验室物件进入功能界面要有过场；从物件进入的界面退出时不应落回终端。整条流程符合玩家直觉。
2. 元件台卡片展示的内容要与放到画布上的元件一致。
3. 优化游戏美术，遵守“Avoid unnecessary secondary labels and descriptions. Let the layout do the explaining”。
4. 第二轮：各物件页面可以有自己的风格，但整体统一为极简未来主义；手册与旅程图保持终端风格；进入动画不能生硬；关卡测试台与引导文字也按布局精简。

## 进出规则（已实现）

| 进入方式 | 过场 | 退出后 |
| --- | --- | --- |
| 点击终端 / Enter / Space | 镜头向屏幕走近；屏幕玻璃长成整幅深色工作区，菜单淡入 | Esc、「返回房间」：工作区收回屏幕，镜头退回 |
| 点击档案、作品、地球仪、成就、手册、设置、信笺 | 镜头转向并走近该物件；一块玻璃面板从物件本身长出铺满画面，内容在面板上淡入 | 关闭页面：面板收回同一物件，镜头退回（不再进入终端） |
| 终端菜单里的按钮 | 无相机移动（已在终端里） | 关闭后回到终端菜单 |
| 在房间按 F8/F10 等全局快捷键 | 页面淡入 | 关闭后留在房间 |
| 终端「开始/继续/旅程地图」进入关卡或地图 | 原有屏幕收成一线光 | 回到实验室时从终端出来，壹直接答复 |
| 旅程板进入地图 | 镜头转向旅程板后收成一线光 | 回到实验室时镜头从旅程板拉回房间 |

- 房间字幕只在房间可见时出现；在终端里得到的完成反馈字幕，会等玩家回到房间再显示。
- 鼠标指向物件时，物件本身提亮；底部提示只写物件名称。去掉“移动鼠标轻转视角 · 点击物件进入”这类说明。
- 减少动效时所有相机移动跳过，状态立即切换。
- 镜头是“走近”（沿视线推进一半距离，再收窄视角），不是长焦挤压；面板跟随物件在屏幕上的实时位置变形（`GlassMorph`），进入约 0.75 秒后即可操作，最后 0.22 秒的面板溶解只是外观。
- 代码：`src/lab/lab_home.gd`（`open_terminal`、`leave_terminal`、`_open_from_room`、`_travel_in`、`_travel_out_from`、`GlassMorph`、`_arrive`），`src/lab/lab_room_3d.gd`（`focus_on` 推进与取景、`region_bounds`、`region_screen_rect`、悬停叠加材质），`src/ui/prototype_hub.gd`（成就页关闭不再强制唤醒终端）。

## 物件页面风格（已实现）

- 同一家族：从房间物件打开的页面统一为实验室的浅色磨砂玻璃（同一底色、1 px 细线、统一 8 px 圆角）。每个物件只带自己的强调色、极淡底色倾向和页面顶端一条 2 px 强调线：档案青、作品玫瑰、成就琥珀、设置蓝、信笺紫。
- 手册、地球仪（旅程回顾）与旅程板（旅程地图）保持终端深色，面板也用终端屏幕色长出。
- 从终端菜单打开同一页面时仍是终端深色；关闭时完整还原（`src/lab/room_page_skin.gd` 的 `apply` / `revert` 记录并恢复每项覆盖）。
- 颜色按角色映射（底、面、线、次要文字、正文、强调），信号 0/1、位宽、警告等语义色保留并在浅底上加深以保证对比；页面里的深色图解（如手册示意图、作品预览）保持为“嵌入的小屏幕”。

## 元件台（已实现）

- 卡片不再使用独立缩略图（`CircuitModuleThumbnail` / 单独的门符号），而是直接放入画布放置时使用的同一个元件节点视图（`_create_component_placement_ghost`），包括端口圆点、模块标题与端口行、自定义封装外形。
- 所有卡片使用同一缩放（0.6），过大的模块再缩小以放进卡片；卡片只保留名称。用途、端口和位宽在元件本身或悬停提示中。
- 测试改为断言卡片中的节点视图与放置预览、画布节点的视觉签名一致。

## 文案精简（已实现）

- 档案：锁定页只显示页码，解锁条件放在悬停提示；去掉页顶说明与空状态说明；“回到终端”改为“返回”。
- 实验室墙面：旅程板去掉“完成/当前/锁定”等状态词，用颜色表示；作品墙空状态不写说明。
- 关卡：视野提示只显示百分比；底栏端口统计、未接线诊断缩短（保留“这不是故障”）。
- 测试台：用例行去掉与按钮重复的“#2 A0 B1”，只写状态（未运行／正在运行／实际 S1 C0 · 通过）；真值表说明段落改为一个可点开手册的“真值表”链接；底栏追踪说明只留“追踪”“等待运行”“低电平 0 也是正常信号”；空结果写“实际：—”。
- 旅程地图：图例行改为章节选择的悬停提示；底部操作说明改为悬停提示；列表中锁定任务只写“未解锁”。
- 旅程档案、成果与存档、设置、术语手册：去掉副标题与范围/来源说明（范围、来源移到悬停提示）。
