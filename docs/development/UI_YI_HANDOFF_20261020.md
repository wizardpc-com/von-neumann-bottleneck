## 1. 壹的“快速输出 + 尾随光标”

**定位（规范 v0.3 的强制澄清）：** SVG 是壹的话**末尾的打字光标**，不是壹的头像、Logo 或卡片前缀。
发言者仍是普通文字标签「壹」；任务目标、按钮、步骤序号、运行结果和成绩照常即时显示，只有壹说的话逐字出现。

| 已实现 | 位置 |
|---|---|
| 统一组件：先排好整段文字（卡片不随字符长高），再按可见字符逐字绘制；光标由实际换行后的字形宽度定位，跟随最后一个已显示字符；显式换行后移到下一行行首；为光标预留行宽，不会伸出文本框 | `src/ui/yi_typewriter.gd` |
| API：`play(text, replay)` / `prepare(text)` / `complete_now()` / `stop()` / `set_reduced_motion()` / `finished` 信号 | 同上 |
| 速度：默认 35 字/秒；设置 → 显示 →「壹的文字速度」慢 22 / 标准 35 / 快 60 / 立即显示（存于 `user://presentation.cfg`，不是存档） | `window_mode.gd`、`prototype_hub.gd` |
| 跳过：点击正文或在所在卡片内按 Enter/Space，**只补完文字**，不同时触发按钮；再按才执行按钮 | `yi_typewriter.gd` 的 `skip_scope` |
| 本次会话已完整读过的话再出现时直接显示全文；减少动效时全文立即出现、光标静止不闪 | 同上 |
| 光标：输出中稳定可见；输出完毕后约 1 秒一周期柔和明暗；关闭/隐藏即收起并停止计时 | 同上 |
| 资源：三份纯净 SVG（无滤镜/光晕），以 4× 栅格 + mipmap 导入；按行高选 16/24/32（正文 16–17px 用 24 号，较大字号用 32 号）；颜色令牌 `YI_TEXT_CURSOR = #F5E5BB` | `assets/narrative/yi_text_caret_*.svg`、`lab_palette.gd` |

**接入的四个场景（规范 §7）：**

1. **实验室终端问候**：唤醒后壹的话逐字出现，光标在句末闪烁；待机标志改为普通电源灯「●」，不再是常驻光标。
2. **NOT 教程**：五个步骤仍由真实操作推进，步骤与说明即时可读；每完成一步，壹的短回应（「接上了。」等）带光标输出后淡出。
3. **完成卡**：先即时显示系统判定与本关收获，约 0.45 秒后壹的短评逐字出现；卡片高度与按钮位置不变。
4. **非模态求助**（硬件序章各关）：「提示 · F1」先在画布右上角打开壹的小卡，输出该关第一级方向提示；
   可选「再具体一些」（进入原有只读提示画布，保留原分级与确认）或「我自己试试」（壹回一句后自行关闭）；
   × / Esc 关闭。小卡不遮挡步骤卡、不抢键盘焦点、不改动玩家方案。

## 2. UI 建议落实

| 建议 | 本轮结果 |
|---|---|
| 地图按「序章 → 第一章 → …」 | 新增 `src/campaign/journey_naming.gd` 统一命名；旅程地图章节栏、下拉框、画布分区标题、任务列表一致：序章、第一章 … 第十章 |
| 关卡名单行：`序章·名称`、`1-1 名称`、支线 `1-4-1 名称` | 主线按章节内旅程顺序编号；可选支线取其所挂主线的编号（如 `1-3-1 一取再用`）；旧的 `C1 ·`、`1 ·` 前缀去掉。地图、列表、工作台标题（序章/第一/二/四章）、完成卡使用同一名称 |
| 地图入口统一称「旅程地图」 | 终端、地图标题、第三/四章与创造工作台的返回按钮；各章内部地图统一称「章节地图」 |
| 手册合并 | 第二章「概念手册」工具按钮去掉，概念条目都已在统一「手册」中 |
| 全屏只留在设置 | 各工作台标题栏不再显示全屏按钮；设置中保留（标注 F11），F11 / Alt+Enter 仍可用 |
| 工作台去掉常驻「反馈」 | 普通版工作台不再显示；完成卡底部有「反馈 · F8」，设置里保留入口，F8 照常。**离线测试者包仍保留工作台反馈按钮**，否则会出现遮挡底栏的浮动备用工具条 |
| 「退出游戏」强调 | 终端与设置中的退出按钮使用克制的暗红（`QUIT` 令牌） |
| 简短分步指引 | 步骤卡从半加器/全加器/锁存器/寄存器扩展到 ALU、RAM 与五个可选支线；CPU、LOAD/STORE 保留原分阶段说明 |
| 快捷键显示 | 「提示 · F1」「运行… · F6」「单步 · F5」「全屏 · F11」 |
| 窗口互不遮挡 | 第三章进入关卡后把电路取景到任务窗与元件窗之间；第四章原有三栏与一次性任务卡保持 |
