# 统一风格与故事呈现 · 第三轮交接（2026-10-20）

接在 [第一轮](UI_YI_HANDOFF_20261020.md) 与 [第二轮](ART_TWO_WORLDS_HANDOFF_20261020.md) 之后。用户本轮给的方向：

1. **故事主线在游戏主体中的呈现**：开场 CG 里没有交代的过渡内容，放在第二、三、四章的结尾，用对话的形式输入剧情，引导玩家思考；其余小关卡在开头、中间、结尾做引导和正反馈。
2. **"解密"的含义**：游戏本身是解谜，剧情呈现上要让玩家逐步解开谜团，设置悬疑的锚点或钩子。
3. 在现有基础上全局优化 UI 与美术风格；在功能不变的前提下改掉不合审美的地方，让所有关卡保持同一种风格、类似的交互方式。

不改仿真、判定、任务 ID、存档格式和作品合同。截图见 [verification/20261020-unified-style](../verification/20261020-unified-style/README.md)。

## 1. 故事：章节结尾对话与钩子（候选文案）

`src/lab/chapter_dialogues.gd` 存放第二、三、四章结尾的终端对话。玩家完成 `chapter_2/capstone`、`chapter_3/synthesis`、`chapter_4/mixed` 后回到实验室，唤醒终端时先播放对话，而不是直接出菜单：

- 每段对话三拍：壹说一段话 → 玩家从两句回应中选一句（以「你：…」显示）→ 壹回答；最后一拍是**钩子**，不给选项，只有「回到终端」。
- 壹的话仍用尾随光标逐字输出；回应选项在壹说完后才出现，可以用键盘选择。
- 每段对话只播放一次；结束后回到正常菜单。对话不显示任何系统事实（结果、解锁），这些仍由系统 UI 负责。
- 第一章结尾和 G3 仍保留原来的一句回应。

**三段对话共同的悬疑线（全部是候选，需叙事组审校或替换）：**

| 章节结尾 | 讲出的过渡内容 | 留下的钩子 |
|---|---|---|
| 第二章 · 少走远路 | 这座城曾经也"把常用的东西放在离人最近的地方"；后来人们只记得东西总在手边，忘了是谁放的 | 「档案里有一段，我一直没有讲完。」 |
| 第三章 · 与等待并行 | 从前的人把所有的等待都交给了壹，于是不再提问；"不解释的答案，听起来就像命令" | 「这座城有一处的布局，我从来没有给任何人看过。」 |
| 第四章 · 各就其位 | 壹问玩家：如果它给的答案和你算出来的不一样，你相信哪一个 | 「你后面会读到一些记录，它们不是我写的。」 |

这三段没有使用林见秋、阿禾等候选人名，也没有把档案内容宣布为正史。

**与旧设计约束的冲突（需主创裁定）：** `docs/design/thought-within-world.md` 第 181 行规定"始祖痕迹最多三处……不给出年代、人格、宗教名称、灾难原因或 AI 意识答案"。本轮按用户新方向（章节结尾用对话补全 CG 未讲的过渡、设置悬疑钩子）写的三段对话，让壹以第一人称谈到城市的过去和"把等待交给我"，已超出那条旧约束的范围。这与 [LAB_JOURNEY_HANDOFF](LAB_JOURNEY_HANDOFF_20261019.md) §4 中"壹按有温度、克制的引导者来写，与'最多三处痕迹'的旧约束不同，以哪个为准"是同一个未决问题。在主创确认前，对话只是候选，可以整段关掉：把 `chapter_dialogues.gd` 的 `DIALOGUES` 置空即可，终端回退到原有的一句回应。

## 2. 关卡的开头、中间、结尾

| 阶段 | 序章（硬件） | 第一章起的所有关卡 |
|---|---|---|
| 开头 | 步骤卡（已有，本轮未改） | **新：「壹 · 这一关」开场卡**——进入关卡时，在底栏上方用尾随光标打出这一关要做什么（取自任务语境「现在：」那一句）；7 秒后自动淡出，鼠标移上去会变透明；不抢焦点、不吃点击、不暂停；每关每次运行只出现一次 |
| 中间 | 步骤卡里壹的短回应、F1 求助小卡 | 原有的任务窗、提示与「壹 · 这一步从哪里来」 |
| 结尾 | 完成卡（系统结果 → 壹的短评） | 同一张完成卡；第二、三、四章收尾再接第 1 节的对话 |
