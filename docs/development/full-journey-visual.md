# 可选旅程观察站 · 2026-10-18

首页和任务地图提供「观察站」与「成长档案」。观察站是可关闭的真实3D候选：
程序几何、独立SubViewport世界、正交相机及三个固定视角；原生区域／任务列表
与空间节点使用同一身份，任务树仍是高效导航。没有角色移动、战斗或城市建设。

## 数据与操作合同

- 仅打开时从`TaskNavigation.journey_tasks()`读取快照；切区域、视角或节点不读写
  模型、不改变导航pending/selected、不写任何进度。关闭返回原宿主页并恢复焦点。
- 点击「在高效任务树定位」前重新核对真实任务仍存在；首页显式定位后才写瞬时
  selected，直接打开原任务树，避免继续游戏逻辑覆盖选择。地图宿主沿原定位函数执行。
- 点击「进入原工作台」前重新读取目录并通过原`TaskNavigation.enter()`核对访问条件。
  入口开放与完成分离；观察站不增加前置，不授予创作当前模型所需的准备支持。
- 灯亮只对应同源`completed`，且排除session、unavailable、readonly及invalid。
  地址预测的临时探索永不成为永久灯；无法核验的保存方案不亮灯，只读作品保留提示。
  测试者只开放入口；不据访问权制造完成记录。没有新增灯光存档或首次历史。
- 灯光是完成记录的候选叙事映射，不表示电路信号、硬件能耗、效率计量或真实历史。
  数字／文字／✓随灯呈现，静音时仍可理解。没有时间驱动的奖励或强制动画。
- 媒体缺失不影响运行：底座、灯柱、灯和地面均由代码生成，文字为原生Control。
  F8保留最高层反馈；反馈可见或拖拽期间不打开观察站，Esc先交给反馈再关闭观察站。
  隐藏时停用3D视口更新。

成长档案采用`JourneyJournal.new()`、`add_child()`、`open()`复用实例；观察站与入口
不修改档案或叙事catalog。首页长构建ID上移避开F8工具条，空间不足时省略显示，
完整身份及源码／批次仍在tooltip，不缩小主入口字号。

## 替换接缝

| 部位 | 当前实现／状态 | 替换约束 |
| --- | --- | --- |
| 空间底座／地面 | `journey_observatory.gd::_build_geometry()`，程序Box/Cylinder | 保持节点实际位置和原生编号选择可达；不嵌入动态文字 |
| 灯柱／成果灯 | Sphere/Cylinder，完成时材质发光与局部光源，未完成熄灭 | 亮／灭不得反转完成语义；保留✓及文字，不凭颜色判断 |
| 固定相机 | `_position_camera()`三视角，无持续移动 | 原生列表可达性不依赖相机；避免强制镜头演出 |
| 面板／按钮 | 现有`instrument_theme.gd`；状态和文本为原生UI | 延用focus/disabled/selected状态与现有字号 |
| 台词与档案 | 档案独立脚本；本文件只挂入口 | 不将叙事映射写成模拟测量、已发生的新历史或新进度 |
