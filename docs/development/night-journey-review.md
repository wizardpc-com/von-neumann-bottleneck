# 全旅程学习与操作审阅 · 2026-10-18

## 证据范围

本记录是 R2 的**目录及语义源码审阅**，不是 60 项逐关运行或真人试玩。
只读核对 `TaskNavigation.tasks()/journey_tasks()`、原章节目录及序章内容包、
`second_act_tasks.gd`、`creation_tasks.gd`、创作目录与合同，抽查相应任务／结果界面。
目录相加为原核心 40 项、表示 5 项、服务 3 项、可选地址预测 3 项、创作路线 9 项。
序章 14 项含 5 个探索支线；「核心 40」在这里指原有内容集合，不表示每项都是必经。
表示／服务／地址预测取决于候选开关，C／P／G 取决于创作开关；本记录不证明导出包已开启它们。

本轮未运行 Godot、原生程序或 Git。真实包逐入口清点、完整操作、存档与反馈验证由主线程另行归档。
任务总量应从真实目录导出，不将本表的计数写进产品逻辑。

## 最多两个 R2 产品候选

1. **优先：第一章缺失证据的具体提示。**
   `src/system_lab/system_lab.gd::_evaluate_completion()` 非诊断分支与
   `_refresh_mission_progress()` 目前把目录返回的原因压成 `progress/required`。
   读取现有 `completion_status()` 的 `reason`，区分尚未运行、仍需相同其他条件下的部件对照、
   仍需规模案例、应用目标或未达标订单。只解释下一步操作／证据，不指定最优硬件或答案。
   最小修改为本 UI 文件、相应中英键与 focused UI checks；目录／回执／保存／基线锁不改。
   验证正例、正确但未满足证据、重新打开已有成绩、非官方实验程序不获得进度。

2. **次选：第三章失败结果的精确定位。**
   `src/overlap_chapter/overlap_chapter.gd::_select_run()` 已显示周期／目标和错误行，
   但正确且超时仅追加通用 `too_slow`；可追加「本案例超出 X 周期」并明确当前案例。
   `_run_official()` 保持全案例达标才通过，错误状态、正确但慢、达标分开；时间线入口保留。
   只读现有 trace/task，无新统计／自动修复／正确调度；测试覆盖运行错误、慢方案、合法不同路线。
