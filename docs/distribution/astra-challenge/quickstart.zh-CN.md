# 第一次游玩

[English](quickstart.en.md) · [游戏介绍](../../../README.md)

**从任务树开始。** 首页右上角可选择语言。打开章节任务树，选择已开放的接线教程，先看任务要求再动手。第一关不要求电路基础，操作会逐步介绍。

## 搭建、检查、修改

1. 从已打开的元件台取一个元件。可以拖到画布，也可以点击后连续放置；右键或 Esc 取消。
2. 按当前任务连接兼容端口。线条交叉不会自动相连；细线、圆端口表示一位信号，宽线、方端口表示多位总线。教程和手册会在需要时解释这些标记。
3. 调试用来看一组输入会发生什么；完整测试检查正式用例。单个例子正确，不代表所有情况都正确。
4. 改错时，Mac 用 ⌘Z / ⇧⌘Z，Windows 用 Ctrl+Z / Ctrl+Y 撤销与重做。光标在文本框中时，优先修改文字。

Mac 可用 ⌘, 打开设置、⌃⌘F 切换全屏；两平台都保留 F10 设置入口。拖动仪表、设置或手册的标题栏可移动窗口，文字和按钮仍按原方式操作。

## 不明白时

重新打开任务说明查看要求，或查图解手册。Hint 由你主动逐层查看，后两级会确认；它使用独立画布，不会改变你的作品。

任务树允许你尝试另一条已开放分支，锁定任务会说明前置要求。回地图不会清空作品；“继续游戏”会定位最近游玩的任务。程序草稿和已应用程序分别保存，写到一半也可以离开。

## 随时停下来

通过设置正常退出，下次打开后继续。更新前备份存档，不要为了试新版删除旧成果；想保留不同电路时可使用命名方案。

## 留下一次具体体验

在关卡内按 F8 或点击反馈，未通关也能写。评分可以不填，具体发生了什么更有用，例如：“我把这个元件拖到这里，以为它会留下来。”意见先存在本机，分享由你决定；游玩不需要账号或服务器。

无法启动时，可以在 [GitHub 提问](https://github.com/wizardpc-com/von-neumann-bottleneck/issues/new/choose)，提供构建编号、系统和复现步骤。不要默认上传整个存档目录或私人日志。平台限制以随包 KNOWN-ISSUES 为准。
