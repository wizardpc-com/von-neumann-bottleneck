# Creation evidence workbench

## Scope

Extend the existing candidate workbench, not the engine or campaign: add a paired
RAW/predictive cost ledger, controlled creative comparison and clearer causal
inspection. Keep all measured conditions and snapshots immutable. Preserve v1
bug-fix delivery; produce one integrated local review patch afterward.

Non-goals: new codecs, scoring aesthetics, changing progression requirements,
remote publication, external services, engine replacement, or production saves.

## Plan

1. Capture paired transports under one source/model/machine snapshot; aggregate
   actual event cycles/operations/traffic and render two comparable cycle bars.
2. Keep bounded measured history; parameter edits mark old results as historical
   without editing them. Failed codec runs remain explicit rather than zero-cost.
3. Integrate independent causal inspector and creation A/B modules as small
   workbench hooks. Inspect conflicts and rerun focused headless suites.
4. Explain rejected legacy RAW C1 evidence without overwriting the original;
   offer only explicitly chosen safe redo/recovery, never credit fabricated work.
5. Verify source identity, patch application, event conservation, deterministic
   replay, interrupted/failed UI paths and existing compatible suites. Package
   patch/files/evidence, with 4.6.3/font/headless boundaries clearly retained.

## Invariants

Simulation and event costs remain authoritative; UI timing never recomputes a
result. RAW can compare costs but cannot restore a learned predictor. Pending
truth stays sealed. G2 allows deliberate sample editing and retraining. Protected
work snapshots are never replaced by draft comparison or display state.
