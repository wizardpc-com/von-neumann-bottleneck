# 难度曲线与试验节奏（完成）

## 目标

中文优先。在既有游戏上降低无助于理解机制的操作负担，把多概念跳跃拆成可自己验证的步骤；保留自由构造和有意义的优化难度。

## 范围与不变量

- 硬件ALU：每组公开测试提供有辨识力的单次调试，使用玩家自己的线路，正式32用例条件保持。
- 第六章服务计划：玩家可一次合并自己选定的连续组，顺序保持，一个操作一次撤销。不自动选择最优组或排序。
- 第三章起始局面：检查错误程序/缺少拓扑是否掩盖重叠调度问题，依据真实初始结果决定是否改进。
- 保留上一轮未提交的内容探索改进、模拟、任务ID、存档格式与正式成果边界。不发布或修改冻结包。

## 实施与验收

1. 对照现行实现判断难点，不照旧研究文档机械修改。
2. 实施局部可玩变化，静态独立审阅。
3. 用隔离Godot中文图形演示观察原始情况、改后操作、真实结果和撤销；按实际画面调整。
4. 只执行受影响的必要检查，记录变化及尚需真人新手验证的难度判断。
