before features are needed without a large simultaneous lesson, and more visual

2. Improve cable silhouette and crossing separation without changing hit paths,
   branch topology, custom colors or simulation. Recheck scalar/bus drags natively.
3. Audit first-use instructions across original, optional and overlap levels.
   Use existing Mission pages and contextual tools; show only a few recommended
   handbook topics by default while retaining complete unlocked lookup. Integrate
   overlap concepts into the same progression-aware illustrated handbook.
4. Add controllable illustrative states for core signal/gate and resource concepts;

5. Isolated checks, native ordinary Game Tutorial/Half Adder and representative
   later chapters, CN/EN and reduced window review. Record scope and gaps, commit
   coherent increments and push main.
