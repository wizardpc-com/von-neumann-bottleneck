## Correction and boundary

A transient presentation flag records an explicit debug or official run attempt.
Live input previews do not count. Before that attempt, accepted direct wire
connections/disconnections show calm bilingual building guidance; the Trace footer
uses its existing first-run explanation. After a run, existing stale-test warnings
remain. Repeated edits, simulation reset and Hint return retain that distinction.
A newly loaded board (including named-workbench or language reload) starts without
current-session run history, matching the existing result-reset boundary. The flag
is not serialized and supplies no simulation, completion or sealing authority.
Other action-specific editor messages and all official-evidence clearing remain.
