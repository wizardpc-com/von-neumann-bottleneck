## 同学测试协议

所有观察标记同一冻结 SHA/包版本、设备、语言、既有知识、是否看过答案。未读方案者先独立体验再参与剧透讨论；人数少时如实记录角色和知情程度。测试者自己操作，卡住先记录位置、原话和操作序列，再给提示，不现场代做。

| 观察 | 要回答的问题与证据 |
| --- | --- |
| 操作 | 找得到入口、编辑、运行、失败原因、保存与继续吗？记录卡住控件和动作 |
| 教学 | 为什么这次更快/更慢？换条件后怎样尝试？记录口头解释，不先念标准答案 |
| 主题 | 转折与结尾记住了什么，是否突然/说教？自由回答，不先念主旨 |
| 声音 | 什么时点刺耳/过响/疲劳？记耳机/扬声器、音量；静音再核对理解 |
| 连续性 | 退出重开后的草稿、历史、命名方案和下一步是否清楚？记录前后状态及保存路径 |

分人覆盖开场、瓶颈、表示准备/跨资产、服务响应/质量、两次结尾，另安排真正完整路径；不能把片段时长相加称普通玩家主线时长。录屏/反馈采集先获参与者同意，材料默认本地且最小化。

每条异议写“具体画面/文案/操作 → 影响 → 证据或理由 → 最小改法”。先修丢成果/阻断运行，再修理解、交互/听感，最后风格。可复现缺陷由实现者修、另一方复核；教学假设交人试；审美偏好由团队选择。正式赛道、截止及 AI/素材披露规则由团队核对官方资料，本轮不代为报名。
