# 创作片段试玩路线

候选版使用独立 CreativeStudio-20261010 档案，不迁移正式玩家存档。
从旅程地图进入创造章节。新档案先按 C1→P1→G1 走一遍真实流程：

1. C1：选择样例、学习规则，运行预测包配送并实际复原。
2. P1：接到未揭晓输入，开始练习，先提交预测再揭晓真值，运行余段。
3. G1：主动断开标准下一段，接上输出回灌。之后进入 G2。

输入模式守卫检查当前模型的真实前置记录；只点击 G2 不会绕过它们。

## 一个可复现的创作尝试

选择 ABAC、ABAD 两段公开样例，记忆2、加权采样，起始片段 A B、种子17、
长度64。主动学习、生成，钉住 A；保留机器和这些参数。
写下目标，例如「少一些 B，多一些 C」。这句话只在本次会话展示，未被评分，
也不会被当作模型输入或保存到作品。

在「样例／记忆」页点击第二段旁的「编辑」，把这一段改为以下24项，
然后点击「替换这一段」：

```text
A C A D A C A D A C A D A C A D A C A D A C A D
```

此时规则仍是原先学得的规则。点击「学习」，查看真正重计的后继计数，
再生成 B。固定配方下，CA 后继计数从 [0,5,0,0] 变为 [0,5,0,6]；
64格中12格改变，第一处在第10格；B由16格变为10格，C由10格变为16格。
这些数字说明这一次操作的结果，不构成通用审美或满意度标准。
可保留 A 或 B，也可修改其他片段继续探索。换种子／起始片段属于自由探索。

## 看与继续改

为选中的实际输出命名并确认保存，打开作品聚焦，在构图选项选择「四轨光句 v1」。
A–D 各占固定一轨，每16格折行，连线来自实际相邻符号；编号对应原输出。
播放、暂停、单步、拖动定位；选「静态总览」可自行滚动。
「解释与定位」能回到这一格的真实生成事件。选择分叉会创建独立草稿，
原作品、完整配方和计算证据保持受保护。

未提交的样例文字在离开时有返回／放弃保护；只保存草稿不会保存这些文字。
旧合法存档和40个原有关卡仍保留。新版本可读旧档；带新增设计证据的档案应使用
当前版本读取，旧版本会拒绝不认识的可选字段。候选版是离线测试包，未公证发布。
