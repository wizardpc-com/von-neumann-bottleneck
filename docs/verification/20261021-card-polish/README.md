## 文案

- 主代理逐项复读 60 项任务卡；[逐项记录](card-copy-audit.csv)包含本轮文字及前后长度。
- 修订 8 项任务短句与 9 组章节展开说明。章节展开说明中文由 1114 字符减至 809（约 27%），英文由 3809 减至 2574（约 32%）。这是展开说明的统计，不是全游戏文本缩减比例。
- 教程保留操作位置、NOT 规则；半加器求助用 CARRY / SUM 的真值表问题引导。其他回应保留可继续验证的问题，去掉重复的规则声明。
- 缓存、表示与状态驻留的回应不再暗示每次都更快或完全不需要搬运。模拟器、存档结构、正式用例和通关条件均未改变。
- 弥拉、洪水、雕像、钥匙仍按[前轮交接](../../development/NARRATIVE_HANDOFF_20261021.md)保留为候选。
