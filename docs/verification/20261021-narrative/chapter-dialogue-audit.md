# 章末 v2：逐段审阅

主控依据实际关卡与当前授权审阅。稿件自称“保持定稿”不构成正史确认，
其中交互规格也不覆盖本次用户要求。下表编号沿用来稿，不作为运行时章节索引。

| 段落 | 核查结果与处置 |
| --- | --- |
| 01 一线成机 | 对应序章14项。保留失败记录的方向可用；“失败比一百次成功有用”不是普遍结论，“只有你能决定”也不宜承诺独占。弥拉与“那时候她还在”既定生死暗示留作候选。本轮用真实接线与运行回应。 |
| 02 时间的去处 | 对应第一章7项。强风暴、医院、救回所有人和失去大部分人均待确认；不能以CPU提速实验推导城市依赖的因果。本轮回应只确认本次瓶颈判断与证据。 |
| 03 少走远路 | 对应第二章7项。缓存隐喻可以帮助理解，但“人离得近就不再检查”是过度概括，也会责备使用便利工具的玩家。替换成达标方案、保留记录、换任务重测。 |
| 04 与等待并行 | 对应第三章6项。洪水、水位过期、备用通道与弥拉行动均待确认。“只有后者救了人”与前文协作链条自相矛盾。真实任务不总是简单“两件事同时发生”；保留工作负载通过、等待位置与另一条路线。 |
| 05 各就其位 | 对应第四章6项。雕像、误认、控制器、钥匙与“今天有人替我做像”涉及故事及视觉事件，均不接入；先前跳过分支不因此完成。回应两种查询共用布局，明确仍可探索其他分支。 |
| 06 表示 | 对应第五章5项。编码转换不是写作署名；“署名收不回来”没有本地作品合同依据。不能假定玩家听完前五章故事。保留换一种写法的技术方向，不接入签名或公开传播承诺。 |
| 07 地址预测 | 对应第七章3项，实际顺序在服务之后。“最近很少问我”没有行为记录支持；“告知者会错则告知不值当”不成立；“错的时候没人兜”制造负担。本轮不接入心理推断或道德评判。 |
| 08 持续状态与服务 | 对应第六章3项。真实场景为4条请求流、共24个请求，核心是共享服务方案、持续状态与成本，不是替3个请求排优先顺序；不能据此宣称玩家决定谁先谁后。整段须按玩法重写，暂不接入。 |
| 09 压缩 | 对应第八章3项。可用方向是同时计算省下与多花的成本；无损压缩不等于少拿内容，“我要完整的”也不是错误选择。删除关于成年、责任与完整性代价的评价。本轮保留还原与规则开销的技术边界。 |
| 10 内容预测 | 对应第九章3项。先承诺再揭晓与逐步记录相符；“每一次都留在记录里”不能暗示永久保留所有历史；等待的成本不能无依据量化为更大。鼓励查看错例，不推断玩家一贯表现。 |
| 11 创造 | 对应第十章3项。保留无标准续文、命名并选择留下；规则主要来自学习结果，不能一概说玩家逐条手写。“想做是最好的理由”替玩家排序动机；“回答放作品第一行”无现成功能。接入真实本地保存、回看与配方分叉。 |
| 尾声 钥匙 | 没有独立任务判定。钥匙交接、城市变化、最终承诺和全屏台词涉及重大叙事与表现决策；全部待主创确认，本轮不新增结局或强制阅读。 |

## 全文一致性

- 12段反复使用“记下了”“你刚才自己动了一下”等，会暗示系统保存了玩家观点。
  当前无此记录合同，不采用这些收束句。连续评判“你学会了”“这比猜对更重要”
  也削弱玩家自行解释结果的空间。
- 引用表把05的B选项写成“那座像本来是纪念她的”，但正文是A；
  把07的B关联到“等是把决定权交出去”，正文没有这句话。
  07到10、09到11也不能称为“上一章”。若未来采用跨章引用，须重新核对编号、
  选项内容与缺席路径；本轮不实现引用系统。
- “每段必须回一句”“自由输入是主路径”与“可整体跳过”存在交互冲突。
  本轮采用现有终端的可选短回应，打字过程中即可返回；跳过不改变进度。
- 标题/身体类比与玩法必须分别核验。例如服务不是排3个请求、表示不是署名、
  压缩不是放弃完整内容。不能只修章节分组就把正文视为可上线。
- 城市事件和人物之间的因果、年代、死亡暗示、雕像原型及钥匙寓意需统一确认，
  否则一段的悬念会提前泄露另一段尚未确定的结局。

本轮仅吸收“操作后说话、保留证据、允许再试、玩家选择留下作品”四个方向。
最终文字见运行时代码；未使用稿件中的新故事事实、自由输入或跨章记忆。
