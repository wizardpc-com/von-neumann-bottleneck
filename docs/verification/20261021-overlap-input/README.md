# 尚在途中：让失败指出未完成的工作

首项调度任务的简短完成条件明确为：处理第0批，恰好完成4周期独立工作，总用时不超过10周期。它沿用已有公开规格，不增加条件，也不透露指令的最终顺序。

对于模拟器原有的 `incomplete` 结果，时间线说明补出实际已输出批次数；要求独立工作时，同时显示实际工作周期和精确要求。计数读取本次 `SimulationTrace.metrics.outputs` 与独立计算事件，不解析玩家代码或重新模拟。仅在全部待处理工作结束后的完整性检查中汇总，因此不会把中断事件的计划时长称为已完成工作。

根代理审订文字；gpt-6.1-sol 子代理只审查代码事实。没有改变模拟器、通关判定、正式用例、存档或提示层级。
