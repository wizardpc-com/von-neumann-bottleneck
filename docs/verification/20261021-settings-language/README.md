# 从设置返回正在阅读的回应

实际完成第二章综合任务并返回实验室后，按 F10 打开设置、切换语言、关闭设置，原界面会把正在阅读的章节回应替换成普通欢迎语，并多计一次实验室访问。

设置页现在复用终端语言按钮的显示恢复逻辑：保留当前回应、段落和已选回复，用新语言显示，关闭设置后接着阅读。临时信息在新界面读取后清空，不保存其他章节的对话，不写入存档。普通关卡仍走原场景重载流程；模拟、任务判定、正式测试和存档结构没有改动。

实际截图还暴露了设置页的返回障碍：720p画面中，面板在隐藏时根据尚未展开的文字宽度算出2384像素高度；显示后文字已经换行重排，面板却没有缩回，返回按钮仍在画面下方。现在设置内容的最小尺寸变化时，复用原适配函数调整面板，正文使用已有滚动区，底部返回按钮保持可见。
