# 实验室主页与放置操作优化 · 2026-10-22

本轮遵照用户要求，**没有打开游戏窗口，也没有新增 GPU 截图**。以下通过项为隔离项目中的无窗口检查，不代表原生键鼠手感、帧率或最终美术验收。

## 最终行为

- 实验室 Esc、终端「退出」、房间设置中的「退出」复用同一组确认控件，显示在真实终端玻璃纹理上。房间保留可见，待机文字隐藏；鼠标通过玻璃的真实三角形命中映射到按钮。其他物件不能穿透确认操作。默认聚焦「否」，Esc 可取消；取消回到原来的房间或终端菜单。确认后的存档与退出仍由原 GlobalSave 负责。
- 房间环境光从偏蓝调整为中性暖色。保留模型、物件分区、镜头和页面边界；这一颜色调整尚未重新目视验收。
- 页面关闭时断开装饰线的 resize 回调，避免改变分辨率时访问已销毁对象；延迟调整窗口前检查实例仍有效。
- 放置预览随鼠标直接更新子控件，不再仅为移动预览请求整张图重绘；关闭吸附时保留小数坐标，预览与实际落点一致。拖放落地不再创建马上丢弃的第二份预览。保留现有吸附、缩放、滚动、取消和编辑权限规则。
