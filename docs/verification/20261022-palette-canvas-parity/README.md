# 元件台／放置／画布一致性 · 2026-10-22

## 修正

元件台中的模块此前使用独立的 96×60 缩略形状，落地使用完整 GraphNode，导致外形比例、标题与端口排布不同。现在全部 23 类逻辑对象统一调用完整节点构造器；卡片仅等比缩放，不重排端口或重画外形。常用比例为 75%，按宽度适配，密集模块保留完整高度。

同时修正两处真实差异：常量预览原来显示「C」，现在直接按配置位宽显示实际数值；预览占位原来未包含 GraphNode 实际保留的标题／内容边距，例如 NOT 声明高度 54、实际高度 78。现在声明占位与实际节点尺寸一致，卡片包住完整预览，放置中心按相同尺寸计算。路由节点的预览布局使用其紧凑边距。

没有修改实际逻辑端口、模拟规则、依赖或存档签名。已有冻结记录不重新生成；源绑定的冻结 bands 同时进入元件台、放置预览和落地节点。测试夹具仅位于隔离 QA 的独立显示目录，不安装到玩家内容。
