# 开场与序章结束 CG

| 影片 | 触发 | 播放结束或跳过 |
| --- | --- | --- |
| 开场 | 新玩家第一次正常启动；没有存档、备份、工作台、实验室或导航历史 | 直接进入实验室主页 |
| 序章结束 | 首次正式通过序章最后的 LOAD/STORE 验证 | 继续原有通关总结与后续章节入口 |

旧档不会补播开场或已完成序章的影片。测试模式、无窗口、脚本、自动截图及开发捕获启动不会播放或消费观看记录。重复验证和普通关卡完成不会触发序章结束影片。

`user://cinematics.cfg` 独立记录两段影片，开始播放前写入；主动跳过或中途退出后不重复播放，重新开始游戏保留记录。通关与玩家作品仍由原验证、存档和来源合同决定。`GlobalSave` 仅增加退出前释放影片的调用，存档格式与签名逻辑没有改变。

影片全屏等比显示，使用黑边适配，声音服从已有全局音量／静音。支持 Esc、按钮及键盘焦点跳过，播放期间暂停游戏，保留全屏快捷键，拦截设置与反馈快捷键。影片缺失会继续后续流程；退出保存失败会先释放影片暂停，再显示原有恢复对话框。

## 媒体

源 MP4 保留，运行资产位于 `assets/cinematics/`。按 [Godot 官方视频说明](https://docs.godotengine.org/en/stable/tutorials/animation/playing_videos.html) 使用原生 Theora／Vorbis；无额外运行时插件。没有裁切、缩放或删去音轨。

| 资产 | 分辨率／帧率 | 时长 | 音轨 |
| --- | --- | --- | --- |
| `opening.ogv` | 1920×1080／30 fps | 45.72 秒 | 44.1 kHz 双声道 |
| `prologue_complete.ogv` | 1280×720／30 fps | 52.36 秒 | 44.1 kHz 单声道 |

原文件、最终资产 SHA-256、大小和编码参数见 [media-manifest.json](media-manifest.json)。FFmpeg 对最终两段视频和音轨完整解码、退出码均为 0；对应 `*-decode.txt` 为空即无解码错误。转换工具仅在忽略的临时目录中，不作为游戏依赖交付。
