## 最终行为

- 实验室在窄于 16:9 的窗口中保持横向构图，档案架与旅程板完整可见；16:9 及更宽窗口保持既有视角。镜头目标、物件、页面和导航不变。
- 作品墙按实际字体宽度显示长名称，保留标题与名称间距；超长部分显示省略号，保存的数据及完整名称不变。
- 壹的文字在逗号等分隔符后停顿两个字符时间、换行后三个、句末标点后四个；小数点连续输出，全文末尾不额外等待。停顿随速度设置和操作提示的加速倍率变化；跳过、重读、减少动态效果沿用即时呈现。
