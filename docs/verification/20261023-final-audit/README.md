# 最后收尾检查与 Claude 交接

基线 `6dae9ec`，Godot 4.7.1 stable。本轮修复三个有明确触发路径的问题，保留仿真、端口、任务和存档格式。

## 修复

1. **第四章 Hint／返回需要多按 Esc。** 缩放手柄的原生悬停提示 PopupPanel 消费第一次按键，工作台的 unhandled 回调没收到它。Esc 现在提前走原处理分支，仍让独占原生窗口、设置、反馈和通关总结优先；随后先关 Hint，再走原保存离开。根视口输入的导航测试由 37 项中 2 失败变为 39 项零失败，新增设置与确认窗口优先级检查。
2. **自动保存失败与 CG 抢占暂停。** 统一的保存恢复入口先结束 CG；已显示恢复窗口时不再启动／消费新 CG。恢复窗口在之前已暂停时仍可交互。
3. **救援另存窗口争抢独占窗口。** FileDialog 原为错误窗口的同级窗口，打开时可报 exclusive-child 冲突；现在挂在错误窗口下，保持暂停时可交互。测试实际触发导出信号并读取合法救援 JSON，确认不能覆盖正式玩家存档。

模式、元件、真实来源和正常玩家存档规则没有扩展或放宽。本轮不重新设计美术或剧情。
