# 游戏／测试模式与 Windows 调试包

正常源码及导出候选默认启动游戏模式。玩家可在实验室「设置 → 模式」切换到测试模式，再切回游戏模式。硬件和第一／二章顶部的原有选择器同步显示。

模式选择不会开启其他开发捕获命令。测试模式提供临时元件，完成记录与游戏模式分离，不会授予正式玩家成果。第三／四章及其他工作台保留原保存／离开守卫，返回实验室后切换；共享工作台设置不直接改变正在编辑的草稿命名空间。

本次整合包含此前元件参考形状、元件台与画布一致性、放置与实验室退出确认、两段 CG。CG 声音接到现有 Effects 总音量／静音总线。
