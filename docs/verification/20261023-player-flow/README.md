# 玩家操作与未提交内容保护 · 2026-10-23

本轮保留既有玩法和视觉方案，修复三类可复现问题：

- 在表示、服务、预测和创造工作台中，从设置退出会交回当前工作台的离开保护；取消后保留草稿、探索和未提交文字。
- 序章、第一、三、四章打开设置后，底层不会再响应撤销、删除、平移或卡片拖动。关闭设置后恢复正常编辑。
- 创造工作台中的非法起始文字也受离开保护。先处理未提交的样例文字，再处理起始文字，最后进入原有草稿保存流程；取消会保留文字并恢复输入焦点。中英文提示框限定宽度并自动换行。

## 修复前证据与夹具修正

`before-initial-attempt/` 保留非法起始文字的旧代码失败，以及初版测试的加载／类型错误。修正测试的提前加载和数组类型后，`before-corrected/` 在旧运行代码上复现四类工作台退出绕过和硬件输入泄漏。`before-final-fixture/` 使用最终跨章节夹具，复现第一、三、四章的设置输入问题。

跨章节测试的临时卡片位置会被自动保存补全到布局记录；修正预期后，相同夹具旧代码失败、新代码通过。第一次 GPU 文字检查还暴露测试脚本点击隐藏标签页按钮的问题；最终测试先切到样例页，核对编辑器实际打开，再切回配方页输入。原失败日志和对应夹具保留，不作为游戏缺陷数目。

## 交付身份与边界

`player-flow.patch` 只包含相对本轮开工快照的代码和测试变化。`scope-audit.json` 核对最终 QA 副本：6 个运行脚本改变，其余 547 个运行文件、资源、本地化文件及工程设置保持不变。最后的提示文案／换行调整由 `dialog-final/` 和最终 GPU 文字回放复验。
