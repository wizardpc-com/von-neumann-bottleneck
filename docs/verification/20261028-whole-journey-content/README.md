# 整体内容审计与旅程闭环

以完整性、趣味性、引导性审查现有60项旅程，中文优先；本轮补齐布局探索反馈、创作收尾和完成度展示，并整合本会话前四轮内容修改。没有增加新任务、奖励、模拟规则或存档格式。公开试玩仍为Alpha4，本轮交付源码main，不替换历史发行包。

## 审计判断与最终行为

| 范围 | 审计判断与内容处理 |
| --- | --- |
| 序章至第三章 | 保留真实搭建、正式测试与观察时间线。整合ALU单次尝试、第三章有效初始方案、继续试验及同条件结果比较，不降低正式目标。 |
| 第四章 | 六关已有从字段、记录、冷热分组到整理、分批及综合取舍的递进，但结果难以连接刚才的操作。新增同订单、同模型最近完整运行的周期/流量/峰值差值；初始参照也显示流量。提示前两层分别提出本关观察问题与单变量尝试，第三层方案保持。 |
| 第五至第七章 | 整合单变量实验问题、沿用自己的前项成果、服务连续组合并与一次撤销、中文预测规则与实测比较。地址预测仍为可选临时调查；服务末项、预测末项在地图增加到压缩入门的推荐关系，不增加前置条件。 |
| 第八至第十章 | 保留成本→机器→记忆→冻结检查的默认顺序。9-3次级练习/检查按钮与主引导统一使用同族v2材料。10-2保存后进入10-3可主动查看作品与结尾，无需重复生成或再保存。 |
| 地图、实验室、成长档案 | 地址预测不保存永久完成，原先60分母使完整成果仍只能57/60。现在完成计数排除3项临时任务，并单列临时探索；60项内容、可进入范围与真实完成判定均不变。 |
| 手册 | 整合三项八页成本/上下文/冻结检查图解、六项实际操作例子以及按当前需要与真实成果开放术语。 |

第四章综合关同时显示本次两单的RAM合计、临时峰值、距1300 B/16 B可选目标的差额和已经获得的成果。正确但尚未达标的完整运行可参与比较；空间不足等未完成运行既不成为性能提升证据，也不覆盖最近完整记录或抹掉历史成果。

创作收尾匹配G3真实支持与已保存作品的配方/输出；若多次保存相同内容，则使用最新那件作品及其名字。主动操作复用原有首次演出规则，结束后打开同一受保护作品。加载旧档、进入单元、10-2保存不会自动播；只读、Test和自动脚本抑制沿用原合同。未看结尾时播放，已看时直接查看作品。
