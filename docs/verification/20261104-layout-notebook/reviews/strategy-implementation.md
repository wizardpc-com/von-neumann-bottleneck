## Behavior and integration contract

`Goals` accepts exactly the three declared fields. Limits are finite integral
numbers in `[-1,1000000]`; JSON integral floats normalize to integers. The default
has no additional cap, while zero remains a real cap. Rule identity binds the
full condition and normalized goal independently from simulation identity.

Ranking deep-copies every supplied row and preserves its metadata. Complete,
correct rows from the requested condition rank by actual total cycles or actual
RAM reads plus writes, after inclusive Q1 and peak-copy filters. Objective ties
use explicit original-position ordering and competition ranks `1,1,3`; no other
metric silently breaks a tie. Ineligible entries follow in original order with
rank zero and reasons `invalid`, `incomplete`, `condition`, `first`, or `copy`.

Ranking requires the full current model metrics, including `error`,
`result_class`, `job_count`, `response_cycles`, and `admission_cycles`, in addition
to the four displayed metrics. It rejects nonfinite/fractional/out-of-range
numbers, incomplete responses, reversed admission/response order, inconsistent
Q1, and a last response differing from total completion. This validates the
current-process measurement contract; it is not a score authentication service.
Root's current Workspace passes `run.metrics.duplicate(true)`, so it retains all
required fields.

Session stores a separate goal per workload. Goal changes count as session work
but do not alter recipe Undo, run history, or the baseline. `replay(plan)` uses
the existing actual-model measurement path, appends and selects that evidence,
and preserves draft/Undo/Redo. `run_current()` delegates to that path.

`restore_checkpoint()` validates the entire drafts/goals maps before committing
any state, rejects unknown scenarios and existing session work, preserves exact
normalized dormant recipe choices, and restores no measurements, Undo, Redo, or
baseline. Partial maps use defaults for missing states. Startup-only calling is
owned by Workspace setup; a fresh all-default session remains eligible for
restore, as specified by the `has_work()` guard.
