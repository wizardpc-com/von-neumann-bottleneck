## 本轮可玩的变化

第四章“我的方案榜”现在可以保留一个当前任务的挑战目标，离开后继续改进。
Game 目标保存在独立侧文件，Test 目标在本次启动的各次访问中保留。目标行、
所选优化目标和实测数值在编辑过程中仍可找到。

分享挑战码只包含有界配方、任务、模型、用例条件和目标类型。导入必须先
严格校验，再用本机模型复算全部订单；外部成绩或通过标记会被拒绝。预览
和设目标保留当前草稿及撤销历史；明确点“载入改进”才产生一次可撤销编辑。
正式挑战继续要求原任务全部达标，严格改善才算胜出，相等为持平。

未知、损坏、超限或身份不一致的挑战文件保护原始字节。旧模型条件保留原码，
不冒充当前成绩。保存失败时可在本次停留继续挑战，并用“保留目标”原样重试；
列表排序不会改变重试的目标。重新进入后，清楚区分此前已保存目标与没有
保存成功的目标。

窗口有方案榜／挑战码两页，中英文最小窗口、Tab／Enter／Esc、文本撤销、
主动复制粘贴和反馈返回焦点已验证。原图检查后提高了只读挑战码的文字与
选择对比度。普通 F8 反馈使用当前窗口，Esc 先关闭反馈，再返回方案榜。

审查发现的两项恢复流程问题及 C1

放宽挑战协议或删掉行为断言。最终反馈路由与对比度调整也完成定向复验。

## 实测改变了模型审查优先级

2555个候选、5110次正式订单执行加代表方案重放，在42.610秒内完成。
1991个正确完整候选符合成本恒等式，13个代表方案的重复／JSON往返 Trace
一致。**这批样本中每关只有一个非支配指标组合**，不是多个最优取舍。

`mixed` 中记录优先、复制冷字段 `[1,2]`、batch1 为
**2207周期 / 944B / 16B**，同时优于之前展示的几个热字段／全复制方案。
分批同时改变查询调度，是其优势来源；这些是当前规则下的有效结果。
我们保留合法成绩，把显式源数据分块与复制的分离建模列为下一项隔离实验，
没有为制造竞争而回改旧成绩或阈值。
[完整范围、公式、原始数据及限制](strategy/README.md)。

[testing.md](../../development/testing.md) 的套件和 GPU 命令重建验证。
