## 可玩行为与计算意义

选中一次已测运行并固定比较基准后，可点“查看差异”，在现有运行证据页
检查两侧的准备、查询、输出成本、实际RAM读写、缓存读计数与每份请求的
就绪／完成／耗时，再跳转到任一侧原始事件。所选减基准的方向及两次方案
身份明确；解释读取已有快照，不重复模拟。浏览保留草稿、尚未提交的数字、
撤销、目标、方案笔记和正式成果；后续明确运行才应用数字一次。

两次温度扫描：直接方案614周期／544B，温度副本672周期／500B。
复制准备花442周期，查询省384周期，合计慢58周期、少搬运44B。
缓存视图分别显示51次读查找、24次命中、27次装入和17次写入；模型的
`requests=68`包含写入，不能充当读命中分母。副本有效载荷68B、分配80B。
Q1完成由307变557；Q2就绪由307变557、完成由614变672、耗时由307变115。
这些是实际阶段差异，不把收益武断归因于某个单独设置。

温度后告警双字段副本按记录／字段排列共享612周期／408B准备；查询从
1424变896，总计2044变1516，RAM1560变1032，分别少528。有效载荷136B，
分配144B。交替查询的响应区间会重叠，不把逐请求耗时求和当作总工作。
RAM只累计`fill`与`write`；读取、淘汰、分配、释放字节仍可在原始事件中
查看各自含义。失败／不完整记录保留原始证据，不制造获胜低分。

两个模型、六种实验条件、正式60项判定、挑战码及v1/v2文件格式均保持。
本地证据一致性检查不构成远程成绩认证或全局最优证明。

## 原始失败、修复及仍开放的观察

- [073450Z](logs/headless/20261105T073450Z/results.json)纯解释首次两项失败：
  测试给`Array[Dictionary]`塞String，先被引擎拒绝；改用JSON解析的无类型
  数组才测试到汇总器。NaN快照改为二进制比对以避免JSON自身警告。
- [074051Z](logs/headless/20261105T074051Z/results.json)新UI首次八项失败：
  F8测试原本聚焦隐藏History，改为当前可见事件表；真实SpinBox失焦会延迟
  应用数值，现先释放已提交值，再延迟恢复待编辑文字。原始
  [焦点诊断](logs/headless/20261105T074810Z/test_round8_focus_probe.log)保留。
- 独立审查发现缓存视图漏显示写入计数，已补上实际值与双语断言。
  原图审查发现换视图继承滚动位置，已把所选解释行滚入视野并复跑／复看。
- 首次GPU结构测试在英文空旧目标路径未创建弹窗，解引用null后仍打印
  `PASS342`；**该次失败**。新增可见弹窗断言与现场诊断，没有重试或直接调用
  绕过鼠标路径；两次独立GPU复跑通过。首次点击失效的确切原因未证实，
  仍列为未复现的输入观察，不能声称已查明并修复。
