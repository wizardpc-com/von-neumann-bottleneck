## 全局缩放研究（需负责人决定；未集成）

工程逻辑分辨率为 1600×900，在 1280×720 窗口中整体缩放约 0.8：14 px 的逻辑字号实际约 11 px。研究分支 `claude/vux-a7-scale-20261108`（`0f00fe0`，已推送，不合并）比较了三种方案：

| 方案 | 做法 | 720p 时 14 px 文字 | 结论 |
| --- | --- | --- | --- |
| A 现状 | 1600×900 逻辑画布整体缩放 | 约 11.2 px | 保持为当前默认 |
| B 只放大字体 | 布局不变，标准控件字体按窗口放大 | 约 14.4 px，但自绘文字仍小 | 不建议：覆盖不全、启动时出现递归 |
| C 1280×720 基准 | 逻辑画布改为 1280×720 | 14 px | 最一致；需另批一次布局适配（第二章回放 36 项重叠失败） |

研究报告与对比图在研究分支的 `docs/verification/20261108b-A7/README.md`（`git show claude/vux-a7-scale-20261108:docs/verification/20261108b-A7/README.md`）；同一分支含六张全分辨率图集（每张约 4.5 MB）。
