## 待负责人审核的取舍

以下改变了默认可见内容或操作，均保留前后截图（见各任务目录）：

1. 第二章：运行由两击改为一击；任务窗与测试台互斥显示；终章进入时只开任务窗。
2. 第三章：时间线固定为底部结果带；打开元件／调度程序会收起结果带。
3. 第四章：固定双栏，取消窗口拖动／缩放；完整比较差值收入详情。
4. 第五章：运行前隐藏空证据面板，改为目标卡；阅读提示移入悬停。
5. 第七章：默认显示请求数量与占位；草稿重置提示移入悬停。
6. 第八至十章：工作台内移除语言切换（设置中保留）；空证据页在需要时才出现。
7. 地图：“继续”目标的描边由脉动改为静止（换取空闲不重绘）。
8. 退出游戏按钮：旅程内的第五、六、七、八至十章不再显示，仅独立实验启动时显示。

## 跨章节观察（需负责人决定）

工程逻辑分辨率为 1600×900，在 1280×720 窗口中整体缩放约 0.8：14 px 的逻辑字号实际约 11 px。本轮各工作台遵守逻辑字号下限，没有改全局缩放策略；是否改为按窗口提高缩放或调整基准分辨率，属于全局决定。
