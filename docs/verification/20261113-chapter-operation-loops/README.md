## Default-scale clarification

The earlier Focus fixture deliberately forced960 logical pixels, where peripheral
buttons could clip. Current CPU probe retains the production1600×900 design scale:
1280×720 physical gives1600×900 logical, and960×640 gives1600×1066 logical. Visible
header/tools remain within the viewport and receive pointer input. Capture mode
uses a64px minimum solely for reproducibility; production WindowMode sets its own
scaled minimum. This is not native minimum-window acceptance and does not claim
that every dense circuit fits at minimum zoom.
