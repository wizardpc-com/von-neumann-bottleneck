# Persistent-context experiment (bounded rules)

Independent experimental scene: `state_lab.tscn`. It does not register a task,
award progression, load a model service, train, or judge intelligence. The older
linear experiment remains available unchanged. All numbers are teaching model
cycles, not measured hardware.

## Numerical contract

Four streams A–D each issue six ordered requests. Each stream has an eight-value
context, initialized to a public nonzero vector. Inputs and initial vectors are
generated by the formulas in `state_model.gd`, shown in the public-data panel,
and copied into Trace. Every request computes:

`h[j] = quantize(0.65 * h[j] + 0.35 * x[j]); score = sum(w[j] * h[j])`.

The eight weights are the previous linear lab's fixed weights. 32-bit mode means
unrounded GDScript floating arithmetic with 4B storage accounting, not a bit-exact
float32 kernel. 8/4/2-bit state rounds to a signed uniform grid on [-1,1]; the state
scale is fixed by this contract and needs no per-record metadata. Weight rounding
uses the same signed grid and a 4B scale header below 32 bits. Quantization occurs
on every update, including when resident: eviction never introduces an extra
rounding. State affects the next request and final state is part of quality.

## Scheduling and costs

All 24 requests are ready at time zero. Players choose round-robin, paired streams
(A/B then C/D), or grouped streams (all A then all B...). Per-stream request order
is never changed. Batches contain the next 1/2/4 requests in that schedule. There
is one sequential executor; no overlap, arrivals, or queueing beyond this public
ready queue. A batch's inputs are read before processing and all its compute is
completed before returning its scores. This makes larger batches delay response.

The local scratch budget is 256B. It reserves `slots * state_bytes + weight_bytes
+ batch * 36` (32B input and 4B result per request). Players choose 1/2/4 automatic
LRU state slots and resident/reload-per-batch weights. Initial contexts begin in
backing memory. A miss reads the current persisted context. A dirty eviction
writes it before the next read. Ending a run explicitly flushes all remaining
dirty contexts; no state can disappear for free. External state storage capacity
is four records, separate from finite local scratch, and is reported explicitly.

Every backing transfer costs a 4-cycle request plus ceil(bytes/4) transfer cycles.
Batch inputs and optionally weights share one read request. State reads and dirty
writes each issue a request. Each request uses 24 weighted-accumulation units at
1 unit per cycle: two recurrence accumulations and one score MAC per component,
at every precision. This is a declared teaching arithmetic unit, not a count of
every scalar multiply/add in a physical implementation. Scores
cost 1 commit cycle and 1 transfer cycle each (4B); response transfers have no new
request setup. Rounding is included in the recurrence operation, equal for all
precisions; this does not claim rounding takes zero time in real hardware, and
there is no low-precision compute-speed multiplier. Peak bytes reflect
the actual maximum live resident records plus reserved weight/batch workspace.

## Experiment goals and evidence

The UI offers two public service contracts over the same requests: throughput
(total <=1040 cycles, peak <=200B, max score/state error <=0.02) and prompt service
(the same limits plus every stream's first response <=240 cycles). These limits
are prototype calibration and may be revised before formal adoption. Valid
execution is separate from satisfying the service contract. Exact alternatives
must survive; reduced precision is optional. Grouped order reduces spills with a
small cache but can miss the prompt-service target; round-robin exposes working
set pressure. Batching exchanges request overhead for response delay and workspace.

The Trace records input, state before/after, physical reads/writes, automatic LRU
decisions, output/reference/error and final persisted state. History stores copied
Trace dictionaries: draft changes cannot rewrite old comparisons. Quality means
error against unrounded recurrence for these 24 requests and four final contexts,
not a general model-quality claim. No playback clock affects simulation.
